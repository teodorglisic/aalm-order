# AALM Order Service

![Language Badge](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)

## 📝 Description
A microservice for managing purchase orders, customer carts, and checkout operations at FHNW.
This project was built as part of my studies (Wirtschaftsinformatik @ FHNW) or as a personal learning project.

## 🛠️ Tech Stack
- **Language:** Java
- **Frameworks & Tools:** Java, Spring Boot, Maven, Spring Security, REST APIs, PostgreSQL.

## 🚀 Key Features
- Shopping cart business logic
- Order lifecycle management
- Communication with the Catalog Service

## 💻 How to Run / Build
To get started with this repository locally:
```bash
mvn clean install
mvn spring-boot:run
```
